# Guide du ski — SPORT GOOD DEAL

Guide de formation feuilletable : https://sgd25.github.io/guide-ski-sgd/

V07.56 : les 14 pages partagent la charte bleu ardoise, turquoise et blanc validée sur la page 12. Chaque page est une image complète en 2400 × 3394 pixels. Les contenus validés sont conservés ; les titres, les repères colorés et les encarts de mémorisation sont harmonisés.

Les sources de mise en page sont dans `sources/guide/` et `sources/page12/`. Les photos de skis sont placées sans déformation. Les anciennes images restent disponibles dans le dépôt et son historique.

Le lecteur permet le feuilletage, l’accès direct depuis les sommaires, la lecture agrandie et l’impression. Un second clic sur la page agrandie, avec la loupe moins, revient à la vue double. Les chapitres ont leurs repères de couleur et la page 8 ouvre les familles avec une grande scène de glisse. Le vrai logo SGD figure dans le lecteur et les pieds de page actualisés. Les pages 13 et 14 présentent le freeride, le freestyle et six modèles réels. La randonnée et le chapitre « Choisir » restent à créer.

V07.56 : les trois longueurs de freestyle sont expliquées par usage (jib −10 cm, polyvalent −5 cm, big air / half-pipe à la taille). Nouvelle scène de freeride en poudreuse profonde. Le Rossignol Sprayer Pro remplace le Faction sur la page 14.
