# V07.89 — Logo de bannière plus lisible

Fichier SVG fourni par le client, conservé octet pour octet, sans retouche des
formes ou des dégradés. Substitution uniquement dans la bannière du site.
Largeur 200px pour les bannières larges, 176px intermédiaires, 144px compactes,
132px sur petit mobile. Le logo ne rétrécit pas dans le conteneur flex.

La hauteur supplémentaire réelle de bannière est déduite de la hauteur de
la double page en mode vue entière afin de conserver le livre complet à l’écran.
Le mode large et le zoom restent inchangés. En-têtes et pieds de pages conservés.

Tests smoke 46 pages et régression Chromium sur six formats, modes large/zoom,
flèches aux bords, défilement, sommaire, impression et absence de chevauchement.
